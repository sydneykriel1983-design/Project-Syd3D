# Contributing to Project Syd3D

Syd3D is a personal project shaped around Syd's creative workflow.

## Before a change

- Read [Vision](VISION.md), [Constitution](CONSTITUTION.md), and [Architecture](ARCHITECTURE.md).
- Check the roadmap and relevant decision records.
- For substantial work, describe the user problem and proposed approach.
- Treat unrecorded technology and feature choices as undecided.

## Change expectations

Keep changes focused, explain their purpose, update relevant documentation, and state user-visible effects and limitations. Explain the role, maintenance, platform fit, and license of any new dependency.

## Review

A review description should explain what problem it solves for Syd, what changed, how to try or check it, what limitations remain, and which documents or decisions need updating. Syd provides product acceptance.
