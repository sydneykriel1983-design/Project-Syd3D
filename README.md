# Project Syd3D

Project Syd3D is a personal project to create a comfortable, capable 3D design environment for conceptual modeling, rendering, animation, and 3D printing.

The project is in its discovery and foundation stage. No implementation stack or geometry kernel has been selected. The project documentation will capture the intended direction, guiding principles, an initial architecture, and a staged roadmap before development begins.
